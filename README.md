# Mauro Centurión · CV web

Portafolio profesional publicado en https://giancen35-sketch.github.io/maurocenturion/

- `datos/cv.json`: toda la información del CV (única fuente).
- `plantilla.html`: diseño de la página.
- `construir.py`: genera `docs/index.html` a partir de los dos anteriores.

Para actualizar: editar `datos/cv.json`, ejecutar `python construir.py` y subir los cambios. GitHub Pages publica la carpeta `docs/`.
